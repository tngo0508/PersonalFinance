# Answer

### Why You Don't See Any Skills

This is a **Planning-only session**, which means I'm running in a mode that can only analyze, investigate, and create
plans — I cannot implement changes, run scripts, or spawn custom agents like the skill browser.

**The 50+ agent skills listed in your project** (like `agent-browser`, `design`, `diagnosing-bugs`, `playwright-cli`,
etc.) are available in **implementation sessions** — the normal mode where an AI agent can actually make changes to your
codebase.

### How to Access Skills

1. **Start a normal implementation session** instead of a planning session. Skills appear automatically when the agent
   has the ability to act on your project.

2. Skills are **contextually triggered** — they don't appear as a menu you browse. When you ask the agent to do
   something (e.g., "take a screenshot", "fix this bug", "deploy to Azure"), the matching skill activates automatically.

3. If you want to **see what skills are available**, you can ask the agent in a normal session: "what skills are
   available for this project?"

### Summary

Skills are not broken or missing — they're simply not visible in planning mode. Switch to a regular implementation
session and they'll be there, ready to assist with your tasks.
