# 0013 – The Landing Page Draws the Skyline with MapLibre over a Self-Hosted OpenStreetMap Extract

**Date:** 2026-10-24  
**Status:** Accepted

## Context

The Landing Page should open on a 3D view of Headquarters (Stanton, California): the Skyline. Its buildings rise like
a growth chart, then the camera slowly orbits behind the hero. A 3D city needs building footprints with heights, and
a WebGL renderer with a tilted, rotating camera. D3 (ADR 0009) draws SVG and has no 3D. The obvious source of
buildings is a public OpenStreetMap tile service. The Landing Page is also the first page a visitor sees, so the
Skyline must not slow it down.

## Decision

1. **MapLibre GL JS draws the Skyline.** It is BSD-3. It is vendored through libman at an exact pinned version, never
   loaded from a CDN at runtime, and loaded only by `Home/Index`, never by `_Layout`. MapLibre is admitted for 3D
   geographic scenes only. D3 stays the choice for bespoke 2D pictures, and Chart.js for standard charts.
2. **The data is a self-hosted OSM extract, not a tile service.** A committed script pulls Stanton's buildings, main
   roads, parks and Coyote Creek from Overpass into one trimmed GeoJSON file under `wwwroot`. The script fails if the
   file exceeds 400 KB gzipped. It is regenerated by hand, not on a schedule. No third party receives the visitor's
   request, so cookie consent, the Privacy Policy and the cookie policy are unchanged.
3. **ODbL map data is allowed with attribution.** The licence policy (ADR 0001 §2, amended by ADR 0009) governs code
   dependencies. OSM data is ODbL, which is share-alike for the database only. Serving the extract publicly as ODbL,
   with "© OpenStreetMap contributors" shown on the Skyline and credited on the Legal Pages, meets it. None of our code
   becomes subject to it.
4. **The Skyline never costs the page speed.**
   - Below 992px wide nothing is downloaded: no script, no data and no poster.
   - At 992px and wider, a WebP poster of at most 150 KB is the only request made up front. MapLibre and the data load
     after the `load` event, once the browser is idle.
   - The poster stays as the final view under reduced motion, reduced data, 2G or 3G connections, or without WebGL.
   - Rendering pauses when the hero is off screen or the tab is hidden.

## Considered Options

- **A public tile host (OpenFreeMap, OSM tiles) or a keyed one (MapTiler, Mapbox):** rejected. A public host sends
  every visitor's IP to a third party. That would need consent gating and new disclosures, and a visitor who chose
  "Essential Only" would see only the poster. A keyed host adds cost and a secret, for a city of about three square
  miles that fits in one small file.
- **three.js:** rejected for now. It gives full artistic control, but the camera, extrusion, lighting and attribution
  would all be hand-written, and MapLibre has them built in.
- **A pre-rendered image or video only:** rejected as the main experience but kept as the poster, so every visitor sees
  the Skyline even when the live scene does not run.

## Consequences

- `libman.json` gains a pinned MapLibre entry (script and CSS). If a Content-Security-Policy is ever added, it needs
  `worker-src blob:` for MapLibre.
- The e2e tests for `/` check the speed rules: a phone-width visit requests none of the Skyline's files, and a desktop
  visit requests MapLibre only after `load`.
- The Skyline shows a city, never an address (see Headquarters in `GLOSSARY.md`).
